# Listas de presença docente

Esta pasta recebe fotografias e digitalizações das listas de presença que comprovam a participação de professores em reuniões, SDD, formações, atendimentos e demais ações do NAPED.

Use o padrão `AAAA-MM-nome-da-atividade-lista-presenca-01.png` (ou `.jpg`) e publique cada conjunto na seção **Registros de participação docente** da página `comprovacoes.qmd`, sempre com a atividade e a data identificadas.

Inclua somente documentos autorizados para publicação.
