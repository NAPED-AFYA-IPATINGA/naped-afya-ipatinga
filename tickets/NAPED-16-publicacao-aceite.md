# NAPED-16 — Publicação no repositório existente e aceite

**Prioridade:** P0 · **Estimativa:** 1–2 dias úteis · **Dependências:** NAPED-15, conteúdo liberado e acesso GitHub válido.

## Resultado esperado

Portfólio aprovado no endereço GitHub Pages da conta JeffersonNetto, com operação documentada para a equipe. O site estrutural pode ser apresentado antes; o lançamento institucional com materiais reais ocorrerá quando o usuário os entregar e aprovar.

## Trabalho

- Resolver autenticação GitHub no momento do envio: nesta sessão `gh auth status` aponta token inválido; não guardar credenciais no repo.
- Conferir repo correto, branch, arquivos a enviar, ausência de material restrito e resultado do QA.
- Receber aceite editorial de identidade, textos, imagens, números, comprovações e URL antes da divulgação institucional.
- Enviar commits ao repositório existente, ativar Pages com GitHub Actions, acompanhar build e abrir URL real.
- Confirmar que projeto de GitHub Pages responde em HTTPS e que links em redes/WhatsApp mostram metadados corretos.
- Registrar URL, data, versão/commit, processo de atualização, proprietário da conta e procedimento de rollback.
- Transferir ao usuário a documentação editorial e o backlog restante; conferir uma atualização controlada feita via VS Code.

## Critérios de aceite

- Repositório de destino e URL real correspondem ao pedido.
- O build está verde, site navegável e conteúdo final aprovado.
- O editor consegue identificar como atualizar, verificar Actions e recuperar a última versão boa.
- Não há placeholders apresentados como resultados de 2026 na versão institucional.

## Verificação

Inspeção final em desktop e celular da URL pública e registro do commit publicado.
